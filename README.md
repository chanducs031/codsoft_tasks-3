# JobBoard Pro - Advanced Job Platform

This project contains the complete JobBoard Pro React application from the uploaded code.

## Files
- `index.html` — complete HTML, CSS, React, and JavaScript/Babel application.

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. The application loads React, ReactDOM, Babel, and Font Awesome from CDNs, so an internet connection is recommended.

## Included features
- Job search
- Job listings and filters
- Job details
- Candidate dashboard
- Employer dashboard
- Job posting
- Job applications
- Login/register UI
- Responsive design
- Mock job and user data
